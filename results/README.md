# Manuscript results

`reported_estimates.csv` transcribes Tables 1–3 of *A Narrow Law and Broad Outcomes: Hair-Discrimination Protections and Black Women's Labor Market* (Vignesh, April 2026).

The estimates, state-clustered standard errors, and p-values retain the precision printed in the manuscript. Rate outcomes use percentage points; log wage income uses 100 × log units. The `source` field identifies the corresponding manuscript table. These values are reported research results and were not generated by a new run of this repository.

The command-line pipeline writes any future estimates to the location specified by `--output`, conventionally the ignored `outputs/` directory. That separation keeps source tables distinguishable from new analytical output.
